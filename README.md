# 馥森阪治 Trio 聚餐點餐與上餐追蹤系統

專為松山松青扶輪社於烏來「馥森阪治 Trio」舉辦之聚餐所打造的長者友善點餐與即時上餐追蹤系統。已正式匯入「**報名人數.pdf**」之 20 組報名名冊（共 34 位出席），依據「規劃.md」之規格精心設計，完美融合馥森阪治的泰雅原鄉森林奢華美學。

## 🌟 核心特色與亮點

1. **長者友善與代客點餐（認人不上桌）：**
   - 已自「報名人數.pdf」正式匯入 20 組出席名冊（PP Rachel, Ian+1, PP Fred, P Robert+1, PP Fruit+2, PP Lawyer+1, PE Eric, PP Aircon+1, PP Concord+1, PP IT Smooth, AG Stainless+1, PP Spring+1, Sophia, Sabrina+1, Margo, Ted+1, Three M+3, J’s mart, Albert, Philip，共 20 組、34 位出席）。
   - **直覺切換點餐畫面（免下拉置頂）**：點擊社友旁醒目的「⚪ 未點餐・點此進入」按鈕，畫面立即直接切換進入置頂的點餐畫面，不需向下拉動滾輪，點選完畢按送出後即自動切換回名單，操作流暢直覺！
   - 姓名旁直接附帶「攜帶人數加減控制（+ / - 及大字彈窗）」，點選時系統自動依登記人數帶出對應份數（例如 +1 自動初始化 2 份，+2 自動初始化 3 份），免除手動重選之繁瑣。
   - 移除固定座位/桌號限制，現場認人上菜。
   - 支援「長者超大字體模式」（右上角一鍵切換，字體放大、觸控按鈕加大至 56px）。

2. **支援多筆點餐（寶眷／來賓同行）：**
   - 單一社友名下可動態新增多份餐點（例如：李大榮 社長 名下點 3 份：A餐x1、B餐x2）。
   - 每一份餐點具備獨立對象標籤（本人、寶眷、同行貴賓）與獨立套餐選擇。

3. **客製化飲食特殊需求（獨立鍵入備註欄）：**
   - 針對每份餐點提供獨立輸入欄位，可直接自由鍵入需求（如：`不吃牛`、`海鮮過敏`、`全素食`、`少鹽少油`、`醬汁分開`等），簡潔直覺。

4. **前後台全自動跨裝置即時連動（Real-time Cloud Sync）：**
   - **零設定高速雲端即時同步**：整合 MQTT over Secure WebSocket 雲端通訊技術，免註冊、免填寫任何金鑰，任何手機或電腦打開網址立即自動同步！外場代點餐或廚房劃記上餐，全場設備 0.3 秒內連動。
   - **本地免連網雙軌備援**：內建 `BroadcastChannel` API 與 `localStorage` 快取，即使短暫斷網也能正常操作，恢復連線後自動上傳最新紀錄。
   - **自訂 Firebase 支援**：亦保留自訂私有 Google Firebase Firestore 備援選項。

5. **主廚備料與即時上餐追蹤面板（廚房後台）：**
   - **備料總覽儀表板（Dashboard）**：置頂即時顯示 總訂餐數、A餐總數/待出數、B餐總數/待出數、出餐進度條。
   - **特殊飲食需求彙整專區**：自動獨立彙整「海鮮過敏」、「不吃牛」等高警示項目，方便主廚提前專鍋備料。
   - **即時上餐追蹤卡片**：
     - 大按鈕 `🔴 點擊上餐`，點擊後瞬間切換為 `🟢 已上餐`。
     - **防呆復原機制**：誤觸可隨時點擊 `↩️ 復原`。
     - **一鍵全上**：社友名下所有餐點可一鍵全數劃單。
     - **智能過濾**：提供「🔴 僅顯示未上餐」，上完餐的卡片自動淡出，廚房畫面越上越乾淨！

6. **名冊總覽、CSV 匯出與列印：**
   - 支援一鍵匯出相容 Excel 的 UTF-8 BOM CSV 檔案（中文絕不亂碼）。
   - 內建 A4 列印格式「主廚備料與上餐核對清單」（附勾選方框）。
   - 支援社友名冊批量貼上匯入與自訂菜單。

## 🚀 快速使用方式

### 方式一：直接以瀏覽器開啟（最快）
直接在瀏覽器中開啟 `index.html` 即可完整運行！

### 方式二：本機 HTTP 伺服器
```bash
# 在本專案目錄下執行：
python3 -m http.server 8080
```
開啟瀏覽器訪問：`http://localhost:8080`

### 💡 雙螢幕／雙視窗連動測試：
1. 點選頁面右上角的 **「雙螢幕連動測試」** 按鈕（或手動開啟兩個分頁）。
2. 一個分頁切換在 **「外場代點餐」**，另一個分頁切換在 **「主廚備料與上餐」**。
3. 在外場點餐送出，後台主廚畫面立即同步；在後台點擊上餐，外場進度即時連動！

## ☁️ Firebase 雲端即時同步設定（跨手機／跨平板）

若當天活動現場需要**多位幹部用各自的手機點餐**，且**主廚在內場看獨立平板**，請設定 Firebase：

1. 前往 [Firebase Console](https://console.firebase.google.com/) 點擊「新增專案」。
2. 左側選單進入「Firestore Database」＞ 點擊「建立資料庫」（安全規則選擇「以測試模式啟動 (Test Mode)」）。
3. 點選專案設定（齒輪圖示）＞「一般」＞ 在下方「您的應用程式」點選「網頁 (&lt;/&gt;)」。
4. 複製 `firebaseConfig` 物件內容，例如：
   ```json
   {
     "apiKey": "AIzaSy...",
     "authDomain": "your-app.firebaseapp.com",
     "projectId": "your-app",
     "storageBucket": "your-app.appspot.com",
     "messagingSenderId": "...",
     "appId": "..."
   }
   ```
5. 回到本系統第四個分頁「設定與同步」，將該段 JSON 貼上並點擊 **「儲存並連線 Firebase」** 即可！所有手機與平板將永久保持即時連線。
